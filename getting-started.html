Try the demo in five steps

  1. Open the LocaleSpec tool window and choose Run demo from the welcome panel or toolbar. It uses synthetic English/French messages without reading your translation files.
  2. Review the five findings: an undeclared argument, an omission to review, a changed currency format, a changed plural offset and a source-change warning.
  3. Select a finding with the mouse or arrow keys, then press Enter to open its message. Double-click also works. Resize columns or scroll horizontally to read longer details.
  4. Choose Capture baseline only when you want to accept the current source state. Select a finding and use Suppress with reason to record an intentional exception. Running the demo again resets its temporary review choices.
  5. Choose Export report to save a separate local JSON file. Review its contents before sharing it.

Understand the controls

In a compact tool window, scroll the welcome panel to read all instructions. Baseline and export become available after a report completes. Suppression also requires a selected finding. Controls are unavailable during a scan, and an incomplete report cannot become a baseline.

Read findings as review decisions

A warning means review is needed; it does not prove a mistranslation. Locales can use different plural categories, and argument omission can be intentional. Unsupported or incomplete content is reported as not checked.

Supported resources

The planned project scan accepts flat UTF-8 JSON objects whose values are strings, using the pinned FormatJS ICU syntax. Nested JSON, YAML and executable configuration files are outside this release. Translation files are not rewritten.
