Frequently asked questions

Development preview

Can I scan my project now?

Project-file scans are not enabled in this preview. The built-in synthetic demo is available while licensing activation and full workflow verification are completed.

Why are some buttons unavailable?

Baseline and export require a completed report. Suppression also needs a selected finding. An incomplete report cannot become a baseline, and controls are unavailable during a scan.

Can I use the keyboard?

Yes. Use the arrow keys to select a finding, then press Enter to open its message. Double-click also works. These interactions were verified in the 2026.1.2-dev WebStorm preview.

Does a warning mean the translation is wrong?

No. Currency, offset, selector and source-change findings request review of intent. An undeclared target argument or malformed supported syntax is a structural defect; an omitted argument can be intentional.

Must every language copy the source plural categories?

No. Plural categories vary by language. The supported syntax is validated without requiring every locale to use the same category set.

Does LocaleSpec translate messages or upload my project?

No. Analysis uses bundled local rules and parsers. The plugin does not send project content to an external service. Optional support uses email and sanitized examples, as described in the privacy notice.

Which formats are supported?

Flat UTF-8 JSON string maps using the pinned FormatJS ICU syntax. Nested JSON, YAML, JavaScript configuration and other frameworks are outside this version. Unsupported constructs are not reported as passed.

What happens when a subscription expires?

The intended paid behavior is to stop new paid scans when entitlement cannot be validated. Your translation files and exported local reports remain accessible. Genuine license-state testing is still required before sale.

What are the configured prices?

The Marketplace sales draft is configured at USD 9/month or USD 90/year for individuals and organizations. Subscription licensing has no perpetual fallback rights. The selected trial is 14 days, with an additional 3-day platform grace period. Paid availability is pending; there is no active public offer.
